📥 백업 (JSON 다운로드)
자산목록·환율·스냅샷·매매이력(배당/입출금 포함)·기타 금융소득·현금흐름 대시보드 입력값을 JSON 파일로 저장합니다. 수익률분석·배당금관리·세금관리는 이 데이터로부터 계산되므로 함께 백업됩니다. 다운로드 후 구글 드라이브에 수동 업로드하세요.
📤 복원 (JSON 불러오기)
구글 드라이브에서 백업 파일을 선택하면 복원됩니다. 덮어쓰기 전에 현재 데이터를 「복원전」 파일로 먼저 내려받고, 복원 후 저장된 값이 파일과 같은지 검증 결과를 보여줍니다.
